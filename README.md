Basic Calculator (Python)
Overview

This project is a simple Python calculator built for educational purposes. The goal was to practice Python fundamentals, including arithmetic operations, functions, and user input handling.

While basic in functionality, this project helped strengthen programming logic and problem-solving skills, providing a foundation for more advanced Python projects in cybersecurity and automation.

Features

Addition, subtraction, multiplication, and division

User-friendly input prompts

Input validation for basic error handling

Modular functions for each operation

Objectives

The objectives of this project were to:

Reinforce understanding of Python syntax and functions

Practice handling user input safely

Build foundational skills for scripting and automation tasks

Environment & Tools

Language: Python 3.x

Environment: Local development environment or any Python interpreter

Tools Used: Built-in Python functions and modules

How It Works

The program prompts the user to enter two numbers.

The user selects the operation (addition, subtraction, multiplication, division).

The program performs the selected operation using dedicated functions.

The result is displayed to the user.

This cycle can be repeated to perform multiple calculations.

Learning Outcomes

Understanding Python functions and modular code

Handling user input and errors gracefully

Building a small, functional project from scratch

Developing a foundation for more advanced projects in automation or cybersecurity scripting
